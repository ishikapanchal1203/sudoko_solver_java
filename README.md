# Sudoku Solver using Backtracking

## Project Description

This project solves Sudoku puzzles using Backtracking and Recursion in Java.

The algorithm fills empty cells one by one. If a number violates Sudoku rules, it backtracks and tries another value until the puzzle is solved.

## Features

- Solves 9x9 Sudoku puzzles
- Uses Backtracking Algorithm
- Uses Recursion
- Validates rows, columns, and sub-grids
- Efficient puzzle solving

## Technologies Used

- Java
- IntelliJ idea

## Concepts Used

- Recursion
- Backtracking
- 2D Arrays
- Algorithm Design

## Output

The program takes an incomplete Sudoku puzzle and generates the solved puzzle.
